# CLAUDE.md

Personal website for Bryce Keeler (brycekeeler.com) — machine learning engineer.
Astro + React islands, deployed on Vercel (server adapter; API routes under
`src/pages/api/` use Upstash Redis via env vars in `.env`).

## Commands

- `npm run dev` — dev server (default port 4321)
- `npm run build` — production build (also generates sitemap)
- `npm test` — vitest (tests in `tests/`, cover `src/lib/trading/`)
- `npm run lint` — eslint over `src` and `scripts`
- `npm run typecheck` — astro check + tsc

Always run build + test before committing. Push only when asked.

## Design language ("gothic terminal")

Monochrome, monospace (JetBrains Mono), black ground. **Never hardcode colors** —
use the CSS custom properties in `src/styles/global.css`:

- Gothic tokens: `--void` (bg), `--ink` (text), `--bone` (emphasis),
  `--dim`, `--faint` (borders), `--ghost` (subtle/art)
- Legacy aliases: `--kana-*` (kept so older component CSS resolves; they map to
  the same monochrome palette). `--kana-green`/`--kana-red` are the ONLY colors,
  reserved for P&L / up-down status semantics.
- Light mode: `html[data-theme="light"]` remaps all tokens to warm
  ink-on-paper values. Anything styled via vars is automatically theme-aware.
  The toggle lives in `BaseLayout.astro` (persists to localStorage, syncs
  `meta[name=theme-color]`).

Conventions: square corners (no border-radius), 1px solid `var(--faint)`
borders, no shadows/gradients/glassmorphism; section headers uppercase +
letter-spaced with a `// ` prefix in `--dim`; list rows separated by
`1px dashed var(--ghost)` ("ledger" style); hover states invert
(`background: var(--bone); color: var(--void)`).

## Architecture notes

- `src/pages/index.astro` — homepage. Contains the **procedural ASCII cathedral**
  generator (value noise + steeple height profile, rendered into a fixed `<pre>`;
  main spire peaks at 75% of viewport width), the JSON-tree index with vim-style
  relative line numbers, the scroll-spy (reading-line + even-share hybrid so
  short pages still walk all sections), and the live status footer (fetches
  `/api/trading/data` and `/api/homelab/data`, hides on failure).
- `src/layouts/BaseLayout.astro` — head/meta, theme toggle, and the site-wide
  command palette (Cmd/Ctrl+K or `:`).
- `src/layouts/DocLayout.astro` — shared shell for inner "document" pages
  (resume, blog, journal, `/projects/*`): crumbs, masthead, section styles,
  markdown `.prose` styles (global, so rendered `<Content />` picks them up).
- `public/og-image.png` — generated by the same cathedral algorithm via sharp.
  The generator script pattern lives in git history / can be recreated; rerun it
  if the cathedral art or name/title changes.
- Terminal (`src/components/terminal/`) — content lives in `data/personalInfo.ts`
  (keep in sync with the resume), themes in `data/themes.ts` (`gothic` default).
- Trading & homelab dashboards (`src/components/trading|homelab|market-viz/`) —
  React apps with their own CSS files that consume the global tokens.

## Gotchas

- Astro scoped `<style>` does not match DOM created at runtime by scripts —
  wrap such selectors in `:global(...)` (see the index line-number gutter).
- The cathedral/hero measures real glyph size; don't assume `ch` ≈ 0.6em, and
  don't cap its column count below viewport width (spire positions are
  viewport fractions).
- `.gitignore` whitelists specific files under `scripts/`; new scripts need an
  explicit `!scripts/<name>` entry to be tracked.
- Footer claims "NO TRACKING" — keep it true: no analytics scripts.
- Resume: single source PDF at `public/Bryce_Keeler_Resume.pdf`; the HTML
  version is `src/pages/resume.astro`. Update both together, plus
  `terminal/data/personalInfo.ts`.
